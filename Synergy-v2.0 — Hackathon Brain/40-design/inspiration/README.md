# inspiration — visual references

Drop screenshots of dashboards, maps, demos, hackathon winners, or any UI that nails the vibe we want.

## Naming
`<source-or-tool>-<what-it-shows>.<ext>`

Examples:
- `datawrapper-energy-poverty-map.png`
- `iea-dashboard-hero.jpg`
- `prior-hackathon-winner-2024-grid-resilience.png`
- `figma-community-energy-dashboard.png`

## Required: 1-line note per image

Whenever you drop an image, also drop a sibling `.md` file with the SAME name explaining what it shows and why it inspires us:

```markdown
---
title: <image name>
type: design
status: draft
updated: YYYY-MM-DD
sources: ["https://source-url"]
---

# <image name>

What it shows: <one line>
Why it inspires: <one line>
What we'd steal: <one line>
```

A screenshot with no note is worthless 3 days later.
