## No-Overclaim Gate

Do not submit if any public copy says or implies:

- a named building is already a resilience hub;
- a named building currently has solar, batteries, backup power, cooling capacity, or a formal emergency agreement;
- Sanctuary actively operates a Virtual Power Plant today;
- tax credits or grants are guaranteed for a named site;
- reachable population is exact when only the 500 m model is used.

## One-Sentence Pitch

Sanctuary ranks trusted Peel buildings that should be hardened first into safe, powered gathering places before the next heat wave or outage.
