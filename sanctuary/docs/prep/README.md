## The absolute essentials (if you read nothing else)

**Say this in 20 seconds:**
> "Sanctuary helps Peel decide which trusted buildings to harden first before the next heat wave or outage. We start with public heat-risk data, add real community buildings people already use, rank the first five candidates with a transparent score, and label what is verified, what is modelled, and what still needs a site audit. Our number one is Malton Community Centre and Library, a real building in Peel's top heat-vulnerability quintile."

**The line they remember:**
> "The safest building isn't the nearest building. It's the one people already trust, inside the heat-risk zone."

**The three reflexes:**
1. Lead with the decision, not the map.
2. Label honesty out loud: verified, modelled, or pending.
3. Use proper nouns: Malton Community Centre and Library, 3540 Morning Star Drive, quintile 5.

**When unsure, fall back to:**
> "This is a candidate hub and a planning estimate. It needs a site audit before anyone treats it as ready."

**Close with:**
> "Harden these five trusted buildings first, then repeat the same honest method across Alectra's service territory. That's Sanctuary."

## Who should own which questions

A mixed team answers better when each person has a lane. Suggested split (adjust to your strengths):

- **Verification lead:** data, honesty, and scoring questions ([`05-hard-questions.md`](05-hard-questions.md) sections A, B, D).
- **A programmer:** the code and technical questions ([`03-code-explained.md`](03-code-explained.md) and [`05`](05-hard-questions.md) section G).
- **Research and pitch:** feasibility, funding, stakeholders, scalability ([`05`](05-hard-questions.md) sections E, F).
- **Everyone, no exceptions:** "Are these already hubs?", hard question 1 (why these buildings not official centres), and hard question 9 (no backup power, aren't they ordinary buildings). These are the ones that decide the room.
