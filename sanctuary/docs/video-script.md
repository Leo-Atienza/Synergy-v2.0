# Sanctuary Video Script

Use `.hackathon/video-script.md` as the master shot list. This file is the Sanctuary-local copy for teammates working inside the project folder.

## 10-Second Anchor

```txt
0:00 — Peel HVI map, one hot spot dark red.
0:02 — Click Malton Community Centre and Library by name and address.
0:05 — Panel opens with honesty labels and candidate details.
0:08 — Top five candidate hubs light up in rank order.
```

Required caption:

> If Peel can harden only five buildings first, Sanctuary ranks these five.

Required panel labels:

- Candidate hub, not currently equipped.
- Reachable population: modelled 500 m estimate.
- Solar/battery: planning estimate, requires site audit.

## Full Arc

1. Heat risk is uneven.
2. Official shelter access is incomplete.
3. Trusted community buildings are infrastructure.
4. Sanctuary clicks one real building and explains why it ranks high.
5. The top five candidate hubs light up.
6. The methods box separates real data from estimates.
7. Close: harden these five first, then repeat across Alectra's service territory.

## Five-Minute Recording Spine

```txt
0:00-0:30 — Open on Peel HVI. "Heat risk is not evenly distributed."
0:30-1:15 — Show the shelter gap. Official spaces matter, but trust, distance, hours, and familiarity decide usability.
1:15-2:15 — Click Malton Community Centre and Library. Read the honesty labels out loud.
2:15-3:20 — Explain the score: heat, people, trust, roof/hardening class, facility suitability.
3:20-4:20 — Reveal the top five and the real-vs-estimated box.
4:20-5:00 — Scalability: repeat across Alectra territory, then add feasibility, funding, operations, and eventual energy telemetry.
```

## Required Visuals

- ArcGIS Web Map: `https://senecatechnology.maps.arcgis.com/apps/mapviewer/index.html?webmap=17951a55fae44a83a330101433dda67a`
- Next.js support site: ranked hub map, Malton detail panel, top-five list, method, honesty, scalability, and judge Q&A.
- Screenshots if live ArcGIS interaction lags: HVI overview, Malton hero panel, ranked top five, real-vs-estimated section.

## Do Not Say

- These buildings are current shelters.
- Any named building currently has solar, battery, backup power, cooling capacity, or emergency agreements.
- Sanctuary actively operates a VPP today.
- Tax credits are guaranteed for any named site.
